# Chocolate Sales Analysis Dashboard (Power BI)

## Overview
An interactive Power BI dashboard that analyzes 3,282 chocolate sales records across 6 countries.

## Tools Used
- Power BI
- Power Query (data cleaning and transformation)

## Data Preparation
- Cleaned and transformed 3,282 sales records using Power Query
- Resolved data inconsistencies to prepare accurate datasets for analysis

## Dashboard Features
- 4 KPI cards
- 5 visuals
- Slicers for country, sales person and month

## Key Insights
- Total sales of $19.79M across 6 countries, with an even split (15% to 18% each) and Australia leading at 18.4%.
- Sales declined sharply from about $1.7M in August to about $0.5M in September.
- The top 5 products are within about $0.1M of each other in sales.

## Dataset
"Kaggle: Chocolate Sales".
